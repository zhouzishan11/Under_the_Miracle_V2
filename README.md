# 神迹之下 (Under the Miracle)

> 神创造世界，但从未直接创造文明。文明，是无数微小选择共同涌现出的结果。

一款用 Python + tkinter 写成的"造世"模拟游戏。玩家扮演一位**神明**，面对一片完全空白的世界。

## 核心玩法

玩家**无法直接创造**国家、城市、军队或文明，只能改变世界的**底层环境条件**：

- 抬升 / 沉降大地（低处自会积水成湖）
- 降下雨水 / 收回水汽
- 送来暖风 / 降下寒霜
- 赐福土壤、播撒草木、播撒走兽
- 降下灾祸

世界中的凡人只有最基础的生存需求、记忆、社会关系和行为倾向。他们**不知道"文明"是什么**，系统也**从不告诉他们**"现在该进入农业时代了"。他们只是不断地：

**寻找食物 → 寻找水源 → 聚集 → 交换 → 分工 → 合作 → 冲突 → 迁徙 → 形成制度**

于是一片空白的世界上，会自然涌现出聚落、职业、贸易、部落、战争、文化乃至文明。

你还可以随时**离开神明视角，降临到某个凡人身上**，以凡人之身亲历自己创造的世界。

## 运行

需要 Python 3.12+，依赖 `numpy` 与 `Pillow`。

```bash
python3 main.py
```

或用 uv：

```bash
uv run main.py
```

## 操作

| 操作 | 说明 |
| --- | --- |
| 左侧地图 | 显示世界地貌、聚落与凡人 |
| 右侧"神之权柄" | 选择要施展的神力，在地图上点击或拖拽 |
| 笔刷 | 调节神力影响的范围 |
| 时间 | 暂停 / 正常 / 2 倍 / 4 倍 |
| 降临人间 | 点击后在地图上点选一个凡人附身；用 **W A S D** 或方向键行走 |

## 项目结构

```
main.py                      启动入口
src/under_the_miracle/
  world.py                   世界底层：地形、气候、植被、动物
  agents.py                  凡人个体：需求、记忆、社会关系、技能、知识
  simulation.py              涌现模拟：聚落、分工、贸易、冲突、迁徙、制度、时代
  gui.py                     图形界面：地图渲染、神之权柄、日志、凡人视角
```

## 涌现链条

```
环境（水、温度、土壤、草木、走兽）
   ↓
凡人觅食、饮水、聚集、交往
   ↓
记忆 → 技能 → 知识（火、工具、狩猎、贮藏、农业、制陶……）
   ↓
聚落 → 分工 → 交易 → 冲突 → 制度（律法、文字、祭祀、城防）
   ↓
城邦 → 文明
```

没有任何一步是被脚本安排好的：如果世界上没有水，人就会渴死；没有草木走兽，人就会饿死；只有当你给了足够的条件，文明才可能自己长出来。
